YellAtMyPC is an program written in GO that lets you talk to llama cpp and your AI agent of choice. Then the output is sent back as Text to Speech, so it can talk back.
Gemma E4B GGUF is recommended. Gemma understands audio natively. 

Requirements:
 microphone and PC attached to microphone.
 llama cpp
 Gemma E4B GGUF + mproj
 This app, YellAtMyPC
